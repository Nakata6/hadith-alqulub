### مصير ملاحظات مراجعة المنصة المتصلة

أرقام المراجعة السابقة **4 و10 و11 و12 و13 و14** تخص MySQL أو الحسابات أو التخزين الخادمي. عولج أثرها على هذه النسخة بإزالة مساراتها من التطبيق المنشور، **ولم ندّع إصلاح كود الخادم التاريخي أو مستودع المنصة الآخر**. لا تشغّل تلك المنصة قبل مراجعتها مستقلة وإصلاح نتائج MySQL والتزامن وعزل الحسابات والتحقق من الرموز وصلاحيات التخزين.

بقية الملاحظات الخاصة باللعبة والتخزين والأوفلاين والواجهة عولجت في هذا الإصدار. ملاحظة تسجيل الترويسات عولجت بإخراج جامع التشخيص من النسخة العامة نهائيًا. لا يوجد خادم تشغيل في المخرجات.

### التخزين والترحيل

- أُبقي المفتاح `hadith-alqulub-platform-session-v1` عمدًا لحماية الجلسات الموجودة؛ يحفظ المحتوى الداخلي الآن `version: 2`.
- أضيفت `activeCard`, `penalty`, `tip`, `roundTips`, `totalTipsShown`.
- البيانات القديمة تُفحص قبل العرض. عند وجود بطاقة مستهلكة دون نتيجة، تستخدم آخر مطالبة محفوظة لتحديدها. لا يمكن إعادة بناء تاريخ قديم محذوف أو إحصاءات دقيقة خارج البيانات المتاحة.
- بيانات الجهاز ليست حسابًا ولا تُزامن. حذف بيانات الموقع من المتصفح يمسحها. البديل في الذاكرة مؤقت فقط.
- يُحتفظ بسجل آخر 30 نصيحة، مع عداد إجمالي مستقل ونصائح الجولة الحالية.

### التحقق المنفذ

- فحص TypeScript والبناء وفاحص حزمة PWA.
- 67 اختبار وحدة/واجهة: تتضمن استعادة آخر بطاقة والعقوبة، منع الاختصارات أثناء الإنهاء والبداية، مقاومة بيانات تالفة وتعذر التخزين، حفظ المظهر، استقلال عداد النصائح، وتنظيف مراقب الجولة التعريفية.
- متصفح Chromium فعلي: إدخال الأسماء أثناء الجولة التعريفية، أدوات الهاتف، قطع الاتصال ثم إعادة التحميل واستعادة البطاقة، فتح نافذة جديدة دون اتصال، حفظ المظهر، تحميل صفحة التوثيق المؤجلة وإعادة تحميلها دون اتصال.
- قياسات 390×844 و320×568 و844×390 و1280×800، مع فحص عدم التمرير الأفقي وظهور الإجراءات؛ فحص نص طويل يتطلب تمريرًا داخليًا.
- فحص طلبات الشبكة: لا طلبات خارجية تلقائية ولا أخطاء JavaScript أثناء مسار الاختبار.
- استُخدم Chromium 133 من حزمة بديلة بعد فشل تنزيل متصفح Playwright القياسي في البيئة. ليس هذا اختبارًا فعليًا لـSafari/iOS أو Android، ولا ادعاءً باختبار تثبيت التطبيق على هاتف مادي.

### حدود باقية وتعليمات الإصدار التالي

- تحتاج أول زيارة إلى الاتصال حتى اكتمال تجهيز الأوفلاين. الروابط المرجعية الخارجية تحتاج إنترنت.
- ما زال البناء يُظهر تحذير حجم حزمة رئيسية أكبر من 500 KB قبل الضغط؛ لا يُعد ذلك عطلًا وظيفيًا، ويمكن دراسة التقسيم لاحقًا.
- لم تجر مراجعة علمية جديدة لمراجع الروايات ولا فحصًا مستقلًا شاملًا لثغرات الاعتماديات.
- ملفات المنصة التاريخية غير المنشورة ما زالت موجودة للمراجعة؛ لا تُستعمل إثباتًا أن PWA تحتاج حسابًا أو قاعدة بيانات.
- مصدر GitHub Pages يجب أن يكون GitHub Actions. لا تخلط بين نجاح تحديث فرع `main` ونجاح نشر الموقع؛ تحقق من نتيجة Workflow بشكل مستقل.
- ملفات `dist/` مولدة ولا تُرفع إلى فرع المصدر. الأيقونات والخطوط المصدرية المحلية تُرفع.

### التحقق قبل التحديث التالي

```sh
pnpm install --frozen-lockfile
pnpm check
pnpm test
pnpm build:static-pwa
pnpm verify:static-pwa
pnpm exec playwright install chromium
pnpm test:browser
```
