# معمارية منصة حديث القلوب

## قرارات التنفيذ

| القرار | الاختيار | السبب |
|---|---|---|
| شكل التطبيق | تطبيق موحّد React + Express + tRPC | يتوافق مع المنصة المهيأة ويحافظ على عقود نوعية بين الواجهة والخادم. |
| المصادقة | Manus OAuth مع جلسة آمنة | الحسابات وصلاحيات المدير متوفرة في البنية المهيأة من دون تخزين رموز دخول في المتصفح. |
| قاعدة البيانات | MySQL عبر Drizzle | مناسبة لعلاقات المستخدمين والاقتراحات والمراجعة وسجل النشر. |
| صلاحيات المحتوى | أدوار `user` و`admin` | المستخدم يدير اقتراحاته الخاصة فقط، والمدير يراجع المحتوى العام وينشره أو يؤرشفه. |
| إشعار المراجعة | إشعار مالك المشروع عند كل اقتراح جديد | يلفت انتباه المدير إلى المحتوى المعلّق من دون كشفه لبقية المستخدمين. |
| تحديثات الإدارة | استعلامات محدثة بعد كل إجراء | لا يحتاج نطاق المراجعة إلى اتصال لحظي دائم؛ وتظهر التغييرات فور إعادة جلب بيانات لوحة المدير. |

## نموذج المحتوى والخصوصية

يوجد مصدران للمحتوى. **المحتوى العام** يشمل بنك اللعبة الأصلي وكل اقتراح وافق عليه المدير ونشره. لا يستطيع المستخدم العادي حذفه. أما **الاقتراحات الخاصة** فتتبع حساب صاحبها، وتظهر له فقط داخل حسابه وجولاته حتى يقرر المدير نشرها.

| الكيان | الحقول الأساسية | قواعد الوصول |
|---|---|---|
| `contentItems` | النوع، النص، المستوى، الحقول المرجعية، المصدر، المنشأ، حالة النشر | يقرأ الجميع العناصر العامة النشطة؛ المدير وحده يؤرشف أو يحذف العناصر العامة. |
| `contentSuggestions` | المالك، النوع، النص، الحقول الخاصة بالنصيحة أو السؤال أو العقوبة، الحالة، ملاحظة المدير، وقت المراجعة | صاحب الاقتراح يقرأ اقتراحاته فقط؛ المدير يقرأ ويراجع الجميع. |
| `contentPublicationLog` | الاقتراح، العنصر العام الناتج، المدير، وقت النشر | سجل تدقيق يمنع فقدان تاريخ الانتقال من الخاص إلى العام. |

تتدرج حالة الاقتراح بين **قيد المراجعة** و**مرفوض** و**منشور**. يستطيع صاحبه حذف الاقتراح فقط ما دام قيد المراجعة أو مرفوضاً. عند النشر يبقى السجل مرتبطاً بالعنصر العام ولا يمكن لصاحبه حذفه. تحتوي الجولات الخاصة بالمستخدم على المحتوى العام النشط إضافة إلى اقتراحاته الشخصية غير المنشورة، من دون إظهارها لأي مستخدم آخر.

## توزيع الجولات

يُحدد حجم الجولة عند إنشائها فقط: تسع بطاقات في الاتجاه العمودي وعشر بطاقات في الاتجاه الأفقي. تدوير الشاشة أثناء الجولة لا يغير مجموعة البطاقات النشطة ولا يسقط منها أي عنصر؛ بل يؤثر في الجولة التالية فحسب. يختار المولد البطاقات عشوائياً من المستويات الأربعة ضمن حدود دنيا وعليا لكل مستوى، ويستبعد العناصر المستخدمة حديثاً قدر الإمكان لتقليل التكرار.

## مسارات المنصة

تظل صفحة اللعب هي المسار الرئيسي بالعربية وباتجاه RTL، مع الاحتفاظ بالمستويات والبطاقات والنصيحة والعقوبة والوضع الداكن. يضيف التطبيق صفحة «اقتراحاتي» للمستخدم المسجل وصفحة «إدارة المحتوى» للمدير فقط. يوثق المستودع مخطط الجداول وملفات migration، وتبقى نقاط الحفظ في GitHub والـ migrations وسائل الاستعادة البرمجية عند أي مشكلة.
