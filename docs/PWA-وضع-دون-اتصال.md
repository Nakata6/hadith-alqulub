# PWA ووضع الاتصال المحدود

تُسجّل المنصة Service Worker يتيح تثبيت «حديث القلوب» كتطبيق ويب ويحتفظ بصفحة اتصال محدود وملف manifest والموارد البرمجية الثابتة التي يحمّلها المتصفح. لا يُخزّن Service Worker طلبات المصادقة أو واجهة tRPC أو ملفات المستخدمين أو المقترحات الخاصة، لأن ذلك قد يعرّض بيانات الجلسة للذاكرة المخبئية.

| المسار أو الوظيفة | الحالة عند انقطاع الاتصال | ما يراه المستخدم |
|---|---|---|
| فتح مسار جديد أو إعادة فتح التطبيق | غير متاح دون شبكة | صفحة اتصال محدود عربية مع زر إعادة المحاولة |
| ملفات الواجهة الثابتة التي حُمّلت سابقاً | تخزين مؤقت محدود | يستفيد المتصفح من نسخة مخبئية من CSS وJavaScript؛ لا تُضمن الخطوط الخارجية قبل تحميلها |
| البطاقات والمنشور العام | يتطلب اتصالاً | لا تُخزّن الاستجابات الديناميكية، وتعود التجربة بعد عودة الاتصال |
| الحساب والمصادقة واقتراحات المستخدم والإدارة | يتطلب اتصالاً | لا تُخزّن الطلبات أو ملفات الجلسة في Cache Storage |
| إرسال اقتراح أو تعديل أو نشر | يتطلب اتصالاً | لا توجد طابور كتابة أو إعادة إرسال تلقائي، منعاً للتكرار والتعارض |

لا يستدعي Service Worker `skipWaiting` تلقائياً. عند اكتشاف نسخة جديدة أثناء استخدام التطبيق، يظهر خيار تحديث داخل الإعدادات؛ يفعّل المستخدم التحديث بنفسه ثم يعاد تحميل الصفحة. لا تَعِد هذه النسخة بقراءة خاصة أو مزامنة أو كتابة دون اتصال.

يظهر زر **«تثبيت التطبيق»** داخل الإعدادات عندما يعرض المتصفح حدث التثبيت القياسي `beforeinstallprompt`. عند القبول أو الرفض تظهر رسالة واضحة ولا يُعاد فتح الطلب تلقائياً. بعض المتصفحات، ومنها متصفحات iOS، لا تقدّم هذا الحدث؛ عندها لا يظهر الزر وتبقى طريقة التثبيت الخاصة بالمتصفح، مثل «إضافة إلى الشاشة الرئيسية»، هي المسار المتاح.
