# سجل تحقق ملخص نهاية الجولة

تم التحقق يدوياً على نسخة التطوير من مسار كامل في شاشة عريضة: بدء جلسة باسمَي «علي» و«فاطمة»، فتح عشر بطاقات متتالية عبر اختصار لوحة المفاتيح، اختيار «أجبت على السؤال» لكل بطاقة، وإغلاق نصيحتي اليوم اللتين ظهرتا عند البطاقة الخامسة والعاشرة.

| نقطة التحقق | النتيجة |
|---|---|
| الانتقال بعد البطاقة الأخيرة | لم تبدأ جولة جديدة تلقائياً؛ ظهرت شاشة «ملخص الجولة». |
| نتائج الجولة | ظهرت 10 بطاقات مكشوفة، و10 إجابات، و0 تخطٍ، و0 عقوبات. |
| المشاركة | ظهر توزيع متوازن: 5 بطاقات لعلي و5 لفاطمة. |
| الخصوصية | يظهر نص صريح بأن الملخص خاص بالجهاز، ولا تُرسل بياناته إلى الخادم. |
| النصائح | ظهرت نصيحتا الجولة في الملخص ويمكن فتح كل منهما من القائمة. |
| الإجراء التالي | ظهرت أزرار بدء جولة جديدة وإنهاء الجلسة مع حفظها. |

أُجري الفحص بعد اجتياز اختبارات Vitest وفحص TypeScript في هذه النسخة.
