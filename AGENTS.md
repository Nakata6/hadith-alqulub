# حديث القلوب — instructions for future maintainers

Read `docs/UPDATE_LOG.md` before changing this project.

- This repository ships the **offline, device-local PWA**, as confirmed by the owner on 2026-10-31.
- Do not restore login, tRPC requests, analytics, remote fonts, or server storage to its runtime. The connected platform is a separate repository.
- Existing `server/`, `drizzle/`, and unused platform pages are historical source, not part of the PWA build. Their presence is not permission to reactivate them.
- Preserve the Arabic content and publication decisions. Content changes need the owner's instruction.
- Preserve valid local sessions. Version/migrate storage; never silently clear a user's data during an update.
- Use `pnpm check`, `pnpm test`, `pnpm build:static-pwa`, `pnpm verify:static-pwa`, and `pnpm test:browser` after behavioral changes.
- The build output is `dist/static-pwa`; GitHub Pages uses `/hadith-alqulub/`. Hash routes permit static hosting and offline reload.
- The service worker's revision and complete precache list are generated by `scripts/build-offline.mjs`; do not manually maintain asset hashes.
- Add a dated entry to `docs/UPDATE_LOG.md` listing changes, tests, migrations, known limitations, and deployment status. Never describe an unrun check as passed.
