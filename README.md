# حديث القلوب

لعبة بطاقات حوارية عربية للزوجين، تعمل محليًا على الجهاز ودون اتصال بعد اكتمال تحميل مواردها في الزيارة الأولى.

[فتح اللعبة](https://nakata6.github.io/hadith-alqulub/)

## نطاق هذه النسخة

هذه نسخة PWA ثابتة: لا حسابات، ولا طلبات API، ولا تحليلات، ولا قاعدة بيانات تشغيلية. تُحفظ أسماء اللاعبين والجلسة والمظهر وفلترة النصائح في تخزين المتصفح على الجهاز نفسه. لا تُحفظ الإجابات المنطوقة ولا تُرسل إلى خادم.

تحتاج الزيارة الأولى إلى الإنترنت لتجهيز الملفات. توضح الإعدادات متى أصبحت اللعبة جاهزة للعمل دون اتصال. يحتاج فتح **المراجع الخارجية** إلى الإنترنت. مسح بيانات الموقع أو إزالة المتصفح قد يمسح الجلسة؛ لا توجد مزامنة أو نسخة احتياطية سحابية. إذا تعذر التخزين تظهر رسالة، ويمكن متابعة اللعب مؤقتًا دون ضمان حفظه بعد الإغلاق.

## الاستخدام

- أسماء اختيارية؛ تُستخدم «اللاعب الأول» و«اللاعب الثاني» عند تركها فارغة.
- مستويات همسات ونبض وأعماق وجوهر، مع جولات متجاوبة مع الشاشة.
- استعادة الجلسة بما فيها السؤال أو العقوبة المفتوحة.
- نصيحة عند الطلب، وسجل آخر 30 نصيحة وملخص مستقل للجولة.
- مظهر فاتح وداكن محفوظ محليًا.
- الأرقام 1–9 تفتح البطاقات المتاحة، و0 يفتح نصيحة؛ البطاقة العاشرة تُفتح بالنقر/اللمس.
- التثبيت من المتصفحات الداعمة؛ في Safari على iPhone يمكن استخدام «مشاركة ← إضافة إلى الشاشة الرئيسية».

المفضلة وإعدادات حجم القراءة ليست ميزات منفذة في هذا الإصدار؛ أزيل وصفها السابق غير المطابق للكود.

## التطوير والتحقق

Node.js 22 وpnpm 10.4.1:

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm test
pnpm build:static-pwa
pnpm verify:static-pwa
```

لا يلزم ملف أسرار أو إعداد خادم. المسار الافتراضي `/hadith-alqulub/`؛ يمكن تغيير `PWA_BASE` إلى مسار ينتهي بشرطة مائلة قبل البناء. يُنشر **محتوى `dist/static-pwa` فقط**. لا يُنشر جذر المستودع باعتباره ملفات اللعبة.

اختبار المتصفح، بعد البناء:

```sh
pnpm exec playwright install chromium
pnpm test:browser
```

يمكن تحديد متصفح موجود عبر `CHROMIUM_PATH`. يمكن لبيئات الأدوات تحديد `PLAYWRIGHT_MODULE` و`CHROMIUM_ARGS`، وهما خاصان بالاختبارات ولا يدخلان التطبيق.

## النشر

الملف `.github/workflows/pages.yml` يتحقق من المشروع ويبني حزمة PWA ثم ينشرها من `main`. يجب أن يكون مصدر Pages في إعدادات المستودع **GitHub Actions**. وصول commit إلى GitHub ونجاح نشر Pages حالتان منفصلتان، ويجب التحقق منهما كلٌ على حدة.

## ملفات مهمة

- `client/src/pages/Home.tsx`: اللعب والحوارات.
- `client/src/lib/sessionStorage.ts`: التحقق من الجلسات وترحيلها.
- `client/src/lib/localStore.ts`: التعامل الآمن مع التخزين.
- `client/public/sw.js`: قالب عامل الخدمة؛ تُولد قائمة التخزين عند البناء.
- `docs/UPDATE_LOG.md`: سجل التحديث وتسليم العمل للمطور أو الذكاء الاصطناعي التالي.
- `AGENTS.md`: قواعد المحافظة على هذه النسخة.

توجد ملفات تاريخية للمنصة المتصلة في `server/` و`drizzle/` وصفحات إدارة غير موصولة. لا تُبنى ولا تعمل في إصدار PWA. المنصة المتصلة لها مستودع مستقل `Nakata6/hadith-alqulub-platform`، ولم تُعدَّل هنا.

## المحتوى

بنك الأسئلة والنصائح وسجل توثيق الروايات موجود محليًا ضمن الحزمة. لا تُغيّر قرارات نشر الروايات دون مراجعة المالك. المحتوى للتأمل والحوار، وليس فتوى أو تشخيصًا أو علاجًا.

خُزّنت خطوط Cairo وAmiri محليًا مع تراخيصها في `client/public/fonts`. الأيقونة المحلية البديلة تحرر التثبيت والبطاقات من خدمة تخزين خارجية.
