# حديث القلوب

> **لعبة بطاقات حوارية عربية للزوجين** تساعد على فتح حوارات هادئة وذات معنى، مع نصائح أسرية موثقة وروايات شيعية قابلة لمراجعة المصدر.

«حديث القلوب» مساحة خاصة للزوجين لاختيار بطاقات حوارية، مشاركة الإجابات، واستكشاف نصائح عملية عن المودة، التواصل، الرفق، وإدارة الخلاف. تدعم المنصة العربية واتجاه RTL، وتبدأ بوضع داكن مريح للعين.

## ما الذي تقدمه المنصة؟

| المجال | ما يتوفر |
|---|---|
| **لعبة الحوار** | بطاقات موزعة عشوائياً على مستويات همسات، نبض، أعماق، وجوهر، مع 9 بطاقات عمودياً و10 أفقياً. |
| **الجلسة الخاصة** | أسماء لاعبين، حفظ محلي للجلسة، دعم اختصارات لوحة المفاتيح، وحالة مرئية للبطاقات التي تم الكشف عنها. |
| **نصائح موثقة** | 41 نصيحة أسرية من مراجع خبراء، و35 رواية شيعية مختارة مع مصدر ورابط مراجعة ظاهرين للمستخدم، ومنها دفعات للتربية الإيجابية والحياة الزوجية والبيت والحياة الاجتماعية وصلة الرحم. |
| **اقتراح المحتوى** | يمكن للمستخدم اقتراح سؤال أو تحدٍّ أو نصيحة؛ تبقى الاقتراحات خاصة بصاحبها حتى يراجعها المدير وينشرها. |
| **إدارة المحتوى** | لوحة للمدير لمراجعة الاقتراحات، قبولها أو رفضها، ثم نشر المعتمد منها للجميع. |

## منهج توثيق الروايات

لا تعرض المنصة الروايات لمجرد تداولها. يتطلب النشر موضعاً وسنداً شيعيين قابلين للتحقق، مع **حكم منشور منسوب إلى مرجعه**: درجة المجلسي المقبولة في الكافي، أو حكم صريح آخر على السند نفسه يذكر صاحبه وكتابه ورابطه. لا تستنتج المنصة درجة من تجميع أحكام الرواة. لا يؤدي ورود النص أيضاً في مصدر سني إلى استبعاده إذا كان الأصل الشيعي مثبتاً، بينما تبقى النصوص الضعيفة والمرسلة والمجهولة أو التجميعية غير المسندة خارج العرض.

تُحفظ سجلات القرار وروابط المراجعة في `shared/hadithPublicationReview.ts`، ويوثق معيار التحقق المعتمد في `docs/معيار-توثيق-متعدد-المراجع-مقترح.md` ومراجعته التطبيقية في `docs/مراجعة-تطبيق-معيار-التوثيق-2026-08.md`، كما يوجد برومبت حوكمة لإجراء بحوث لاحقة في `docs/برومبت-حوكمة-محتوى-حديث-القلوب.md`.

> المحتوى الديني المعروض للتأمل والحوار العام، وليس فتوى أو بديلاً عن سؤال أهل الاختصاص في القضايا الشرعية أو الأسرية الخاصة.

## التقنية

المنصة مبنية بـ **React 19** و**TypeScript** في الواجهة، و**Express** و**tRPC** في الخادم، مع **Drizzle ORM** و**MySQL** للبيانات، ومصادقة Manus OAuth. تستخدم Vitest لاختبارات الحراسة ووحدة المنطق.

## التطوير المحلي

```bash
pnpm install
pnpm dev
```

وللتحقق قبل أي تغيير:

```bash
pnpm test
pnpm check
```

## بنية المجلدات المهمة

```text
client/src/pages/Home.tsx          شاشة اللعبة والواجهة الرئيسية
client/src/lib/game.ts             كتالوج النصائح ومنطق الجولة
shared/hadithPublicationReview.ts  سجل توثيق وقرار نشر الروايات
shared/originalGameData.ts         بنك الأسئلة والنصائح الأصلي
docs/                              مراجعات المصادر وبرومبت حوكمة المحتوى
server/                            إجراءات tRPC ومنطق الخادم
```
