# حديث القلوب — نسخة الأوفلاين (PWA)

هذا الفرع هو الإصدار العام الثابت من **حديث القلوب**. افتح اللعبة من [GitHub Pages](https://nakata6.github.io/hadith-alqulub/). بُنيت هذه النسخة من واجهة React الحديثة وكتالوج اللعبة المعتمد في المنصة، لكنها تعمل في المتصفح بلا خادم أو حسابات؛ تحفظ الجلسة محلياً على الجهاز بعد الزيارة الأولى.

| المستودع | وظيفته | طريقة الاستخدام |
|---|---|---|
| `Nakata6/hadith-alqulub` | PWA عامة ثابتة للأوفلاين. | [فتح اللعبة](https://nakata6.github.io/hadith-alqulub/) وتثبيتها من المتصفح إن أتاح ذلك. |
| `Nakata6/hadith-alqulub-platform` | منصة كاملة خاصة تشمل الحسابات والاقتراحات والمراجعة والإدارة. | تُشغّل من خلال نشر Manus فقط. |

## حدود هذه النسخة

تتضمن النسخة العامة لعبة البطاقات الحديثة، الحفظ المحلي للجلسة، زر **«نصيحة»** واحداً يعرض نصيحة عشوائية، صفحة التوثيق العامة، والوضعين الداكن والفاتح. لا تعرض سجل النصائح أو تصفيتها، ولا تتصل بواجهة API أو tRPC أو OAuth.

لا تتضمن الحسابات أو اقتراحات المحتوى أو الإدارة أو قاعدة البيانات أو النشر الجماعي. هذه ليست ميزات معطلة من دون معالجة؛ بل جرى حذف مساراتها من حزمة GitHub Pages عمداً حتى لا تظهر أزرار مكسورة أو طلبات خادمية غير صالحة.

تفاصيل نطاق العمل دون اتصال وخطة الإرجاع الآمن للميزات الخادمية موثقة في [STATIC_PWA_FEATURES.md](./STATIC_PWA_FEATURES.md) و[PROMPT_FUTURE_SERVER_FEATURES.md](./PROMPT_FUTURE_SERVER_FEATURES.md).
