# حديث القلوب

> **لعبة بطاقات حوارية عربية للزوجين** تساعد على فتح حوارات هادئة وذات معنى، في تجربة خاصة تعمل دون اتصال.

[**افتحا اللعبة الآن**](https://nakata6.github.io/hadith-alqulub/)

«حديث القلوب» لعبة محلية للزوجين، صُممت لتمنحكما مساحة آمنة ولطيفة للحوار حول المودة، التواصل، حسن المعاشرة، الأسرة، والتربية. لا تحتاج النسخة العامة إلى حساب أو خادم، ولا ترسل أسماء اللاعبين أو سجل الجلسة أو المفضلة إلى أي جهة.

## ما الذي تقدمه نسخة PWA؟

- واجهة عربية كاملة باتجاه RTL.
- جلسة محلية للاعبين، مع إمكانية إدخال الأسماء أو المتابعة بالمسميين «اللاعب الأول» و«اللاعب الثاني».
- بطاقات حوارية موزعة عشوائياً على مستويات: **همسات، نبض، أعماق، وجوهر**.
- توزيع متنوع يقلل تكرار الأسئلة عبر الجولات.
- بطاقات بنسبة ثابتة ومناسبة للهاتف واللوحي وسطح المكتب، مع تكيّف عدد البطاقات مع اتجاه الشاشة.
- زر **نصيحة** يعرض نصيحة واحدة عند الطلب، بدلاً من عرض الكتالوج كاملاً.
- سجل محلي لما فُتح في الجلسة، وملخص قابل للطي في نهاية الجولة.
- حفظ الأسئلة والنصائح المفضلة على الجهاز فقط.
- حفظ واستعادة الجلسة محلياً، مع دعم العمل دون اتصال بعد الزيارة الأولى وتثبيت التطبيق على الأجهزة المدعومة.
- وضع فاتح وداكن، وإعدادات قراءة محدودة لا تغيّر هندسة البطاقة.
- اختصارات لوحة المفاتيح على سطح المكتب: الأرقام **1–9** لفتح البطاقات، و**0** للنصيحة.

## الخصوصية وحدود النسخة العامة

هذه النسخة **PWA ثابتة ومحلية**. لا تحتوي على تسجيل دخول، ولا حسابات، ولا قاعدة بيانات، ولا اقتراحات محتوى، ولا لوحة إدارة. البيانات المؤقتة والمفضلة محفوظة في تخزين المتصفح على الجهاز نفسه، ويمكن حذفها من إعدادات المتصفح أو من خيار الخصوصية داخل التطبيق إن كان متاحاً.

لا تعرض اللعبة مكتبة النصائح أو الروايات كاملة للاعبين؛ تظهر النصيحة عند طلبها، ويمكن الرجوع فقط إلى ما فُتح سابقاً ضمن الجلسة. المحتوى الديني المعروض للتأمل والحوار العام، وليس فتوى أو بديلاً عن سؤال أهل الاختصاص.

## المصادر والمحتوى

تضم اللعبة نصائح أسرية عملية من مراجع خبراء، ونصوصاً وروايات شيعية مختارة وفق سجل مراجعة وحوكمة مستقل داخل المشروع. لا تُضاف الروايات إلى الكتالوج لمجرد شيوعها؛ بل تُراجع صياغتها ومصدرها وحالة توثيقها قبل اعتمادها. يُفضّل الرجوع إلى المصدر الأصلي وأهل الاختصاص عند الحاجة.

## التطوير المحلي

يُبنى إصدار PWA من مصدر المنصة عبر:

```bash
pnpm build:static-pwa
pnpm verify:static-pwa
```

بعد اجتياز الفحوصات، تُنشر محتويات `dist/static-pwa` إلى GitHub Pages. لا تُنقل ملفات الخادم أو الأسرار أو بيانات قاعدة البيانات إلى المستودع العام.

## ملاحظات تقنية

المشروع مبني بواجهة React وTypeScript، ويستخدم Service Worker للتخزين المؤقت والعمل دون اتصال، مع خطي **Cairo** و**Amiri** محليين لضمان ثبات الخط العربي عند انقطاع الإنترنت.

## الخصوصية والترخيص

يرجى عدم وضع بيانات شخصية أو مفاتيح وصول أو محتوى خاص داخل المستودع. هذا المشروع مخصص لتجربة حوارية خاصة ومحترمة بين الزوجين.
